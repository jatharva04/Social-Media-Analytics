# 🧹 Social Media Analytics – Data Collection & Cleaning  

### 📘 Overview  
This experiments focus on **collecting and cleaning data** from popular social media platforms such as **Reddit**, **Twitter**,**youtube** and **Instagram**. The goal is to prepare unstructured social media data for further analytical tasks like sentiment analysis, topic modeling, or visualization.  

---

### 🎯 Objective  
To extract raw data from multiple social media sources and perform cleaning operations to remove noise, duplicates, and irrelevant information.  

---

### ⚙️ Procedure  
1. Collected posts, captions, and comments using APIs or scraping tools.  
2. Stored raw data in structured CSV format.  
3. Performed text cleaning:  
   - Removed URLs, emojis, mentions, and special symbols.  
   - Converted text to lowercase and removed stopwords.  
   - Handled null values and duplicates.  
4. Verified the final dataset to ensure consistency and readability.  

---

### 📊 Result  
A cleaned and structured dataset was successfully prepared, suitable for downstream analysis such as sentiment detection and trend visualization.  

---

### 🧠 Conclusion  
The experiment demonstrated the process of **social media data extraction and preprocessing**, which forms the foundation for advanced analytics in Social Media Analytics (SMA).
